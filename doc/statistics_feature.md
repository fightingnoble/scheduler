# 统计信息收集功能说明

## 概述

本功能为调度器仿真添加了全面的统计信息收集能力，可以收集和分析仿真过程中的各种性能指标。

## 主要功能

### 1. 任务完成统计
- **总完成数**: 正常完成的任务数量
- **总超时数**: 超过截止时间的任务数量  
- **总延迟数**: 延迟完成的任务数量

### 2. 延迟统计

#### 2.1 端到端延迟统计
- 平均延迟、最小延迟、最大延迟
- 总延迟和样本数量

#### 2.2 单任务延迟统计
- **整体统计**: 所有任务的延迟汇总统计
- **按任务名称分别统计**: 根据任务名称（去掉超周期标号）分别统计每个任务的延迟

**重要特性**: 
- 自动识别任务名称中的超周期标号（如 `task1_0`, `task1_1` 等）
- 将同一基础任务在不同超周期下的延迟合并统计
- 为每个任务提供独立的延迟统计信息

### 3. 重分配统计

#### 3.1 分区级重分配统计
- 每个分区的重分配次数
- 每个分区的累计重分配时间
- 每个分区的平均重分配时间

#### 3.2 系统级重分配统计
- 总重分配次数
- 总重分配时间
- 总重分配成本（重分配时间 × 分区容量 × 基础算力）

## 使用方法

### 1. 基本使用

```python
from approach_def import StatisticsCollector

# 创建统计收集器
stats = StatisticsCollector()

# 初始化分区统计
stats.init_partition_stats("acc_p0", 100, 1.0)
stats.init_partition_stats("acc_p1", 200, 2.0)

# 记录任务开始
stats.record_task_start("task1_0", 0.0)

# 记录任务完成
stats.record_task_completion("task1_0", 5.0, 4.0, False)

# 记录重分配
stats.record_reallocation("acc_p0", 0.1)

# 获取统计摘要
summary = stats.get_summary()
stats.print_summary()
```

### 2. 在仿真中使用

```python
# 在仿真主循环中
def run_simulation(processors, event_t, G, stats_collector=None):
    # ... 仿真逻辑 ...
    
    # 仿真结束后输出统计摘要
    if stats_collector:
        stats_collector.print_summary()

# 调用工厂函数时，统计收集器会自动创建
processors, event_t, stats_collector = instantiate_processors(
    G, partition_cfg, event_t, policy="pglb"
)
```

### 3. 任务名称处理

统计收集器会自动处理任务名称中的超周期标号：

- `task1_0` → 基础名称: `task1`
- `S1_1` → 基础名称: `S1`  
- `OP2_-1` → 基础名称: `OP2`

这样可以将同一任务在不同超周期下的延迟合并统计。

## 集成说明

### 1. 处理器集成
- `BaseProcessor`, `Sen_p`, `Acc_p` 类已集成统计收集器支持
- 统计收集器通过工厂函数自动创建并分配给各个处理器

### 2. 仿真集成
- `run_simulation` 函数已支持统计收集器参数
- 仿真结束后自动输出统计摘要

### 3. 工厂函数集成
- `acc_p_factory` 函数自动创建统计收集器并分配给所有加速器处理器
- `instantiate_processors` 函数自动创建统计收集器并分配给所有处理器
- **无需手动创建或传递统计收集器**

## 注意事项

1. **任务名称格式**: 超周期标号应为 `_数字` 格式，如 `_0`, `_1`, `_-1` 等
2. **性能影响**: 统计收集会增加少量计算开销，建议在需要分析时启用
3. **内存使用**: 统计收集器会保存任务开始时间，长时间仿真时注意内存使用
4. **线程安全**: 当前实现不是线程安全的，多线程环境下需要加锁保护

## 扩展功能

可以根据需要扩展以下功能：

1. **更多统计指标**: 如任务等待时间、资源利用率等
2. **统计导出**: 支持导出为CSV、JSON等格式
3. **实时统计**: 支持仿真过程中的实时统计信息显示
4. **统计分析**: 添加更复杂的统计分析功能，如分布分析、趋势分析等
